# InsightFlow-Automated_Business_Insights

## 📌 Project Overview

InsightFlow is an automated data analysis platform designed to simplify the process of transforming raw datasets into clean, validated, and meaningful business insights.

The application performs data profiling, data quality validation, cleaning, pattern detection, and automated analysis through an interactive Streamlit interface.

## ❗ Problem Statement

Traditional data analysis workflows often require significant manual effort to inspect datasets, identify data quality issues, clean inconsistent data, and perform repetitive analysis before meaningful business insights can be generated.

This process can be time-consuming and may lead to inconsistent analysis when datasets contain missing values, duplicate records, incorrect data types, outliers, or other quality issues.

InsightFlow addresses this problem by providing an automated workflow for profiling, validating, cleaning, analyzing, and visualizing datasets through a single interactive platform.

## 🎯 Objective

The goal of InsightFlow is to reduce the manual effort involved in preparing and analyzing datasets by providing an automated workflow from raw data to business-oriented insights.

## ⚙️ Core Engines

InsightFlow follows a five-engine architecture:

1. Data Profiling Engine
2. Data Cleaning Engine
3. Pattern Detection Engine
4. Automated Analysis Engine
5. AI Insight Engine

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/Lakshmipriya-datahub/InsightFlow-Automated_Business_Insights.git
cd InsightFlow-Automated_Business_Insights
```

2.Install the required dependencies:

```bash
pip install -r requirements.txt
```

3.Run the Streamlit application:
```bash
streamlit run app.py
```
